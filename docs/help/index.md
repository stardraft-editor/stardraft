# StarDraft 2 help

StarDraft 2 is a map editor for StarCraft: Remastered. These pages tell how to use it and what the game's data does.
The same pages are in the program (Help > Documentation, or F1) and on the web.

## Start here

- [Getting started](getting-started.md): open a map, edit it, and save it.
- [Values and units](values-and-units.md): frames, pixels, tiles and the other units of the game's data.
- [Keyboard shortcuts](keyboard-shortcuts.md): the keys of the menus, the map, the trigger editors and the lists.

## Triggers

- [Trigger checks](trigger-checks.md): what each mark in the Triggers workspace means, and what the checks do not find.

## The game's data (.dat files)

The Data workspace of an EUD project changes the game's .dat files for your map. Each page tells what each field does
in the game, how the game keeps its value (the raw value), and the value in a unit that is easier to read.

- [Units (units.dat)](units-dat.md): hit points, weapons, costs, sounds and more for each unit.
- [Weapons (weapons.dat)](weapons-dat.md): damage, range, cooldown and splash.
- [Movement (flingy.dat)](flingy-dat.md): speed, acceleration and turn speed.
- [Sprites (sprites.dat)](sprites-dat.md): the image of a sprite and its selection circle.
- [Images (images.dat)](images-dat.md): graphics, animation scripts and overlays.
- [Upgrades (upgrades.dat)](upgrades-dat.md): costs and research time of each level.
- [Technologies (techdata.dat)](techdata-dat.md): costs, research time and energy.
- [Orders (orders.dat)](orders-dat.md): what each order does and how it targets.
