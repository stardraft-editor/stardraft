**This is a preview build for testing. It is not the latest release.**

StarDraft 2 is now one program for Windows, macOS and Linux. This preview lets you try it early. Report the problems
that you find, so that they are fixed before the release.

## Downloads

- **Windows**: `StarDraft-<version>-win64.zip`. Unzip it and start `StarDraft 2.exe`.
- **macOS** (Apple silicon): `StarDraft-<version>-macos-arm64.dmg`. Open it and drag StarDraft 2 to Applications. The
  app is not signed by Apple yet: the first time, right-click the app and select **Open**.
- **Linux** (x86-64): `StarDraft-<version>-x86_64.AppImage`. Make it executable (`chmod +x`) and start it.

You must have StarCraft: Remastered installed. If StarDraft 2 does not find it, the start page shows **Browse…**.

## Before you test

- Make a copy of the maps and projects that you open with this preview.
- The preview uses the same settings as StarDraft 2 0.5. You can go back to 0.5 at any time.
- Check for updates in 0.5 does not offer this preview, and the preview does not update itself to a newer preview.
  Download a new preview from the releases page.

## What is different from 0.5

- The text and some controls look a little different, because the program draws them itself on each system.
- The program uses more memory than 0.5.

## Report a problem

Use **Help > Report feedback** in the program, or open an issue on GitHub. Write which system you use (Windows,
macOS or Linux) and the steps that cause the problem.
